## ⚠️ Kernel Breach & System Purge Simulation Prank 

- An interactive, browser-based prank simulation that mimics a critical Windows system terminal purge sequence. 
- Features realistic sound effects, terminal typing animations, a customized progress bar, and a Matrix rain reveal screen at the end to assure users that no actual system files were touched.

---

## 🚀 Features

* **Realistic Windows CMD UI**: Custom scanline overlay, window headers, control buttons, and authentic Windows version prompts.
* **Dynamic Audio Feedback**: Built using the Web Audio API to generate real-time keypress clicks, warning alarms, and completion chimes without external audio assets.
* **Interactive Prompt Handling**: Responds to real keyboard inputs (`Y`/`N`/`Enter`/`Backspace`) with input buffering.
* **Fake Purge Sequence**: Animates progress bars destroying Windows system files, registry entries, hardware drivers, and security modules.
* **Matrix Rain Reveal**: Ends with a canvas-based Matrix digital rain animation and a friendly safety confirmation card.

---

## 🛠️ Tech Stack

* **HTML5** - Page structure, canvas, and layout
* **CSS3** - Custom terminal styling, animations, and CRT scanline overlay
* **JavaScript (ES6+)** - Async sequence handling, Web Audio API synthesis, dynamic canvas rendering
